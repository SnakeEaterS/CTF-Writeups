# CTF Write-Ups & Cybersecurity Learning

This repository contains write-ups and documentation for Capture The Flag (CTF) challenges I have completed as part of my ongoing journey in learning and practicing cybersecurity.

The purpose of this repository is to:

* Document the challenges I have completed and the approaches I used to solve them.
* Record the techniques, tools, and concepts I learned throughout each challenge.
* Improve my ability to analyze problems and document technical solutions clearly.
* Track my progress and development in different areas of cybersecurity.
* Build a personal reference that I can revisit when learning or solving similar challenges in the future.

Not every CTF I have completed is currently documented, as I only started maintaining this repository in September 2026. I plan to gradually add write-ups for future challenges and, where possible, document some of my earlier work.

Each write-up focuses not only on the final solution, but also on the **reasoning, investigation process, mistakes, and lessons learned** along the way. This is intended to make the repository a learning log rather than simply a collection of answers.

> **Note:** These write-ups are intended for educational purposes and cybersecurity practice. Techniques and tools described here should only be used in environments where you have permission to test.
